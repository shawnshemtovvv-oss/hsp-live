How these numbers are worked out
Hand G/L
End stack minus start stack for that hand.
Day G/L
A player’s running total of Hand G/L, the same way the event dashboard counts it. It leaves out chips added or taken off between hands (rebuys, top-ups and side transfers), so it measures results at the table, not net cash. That is why a player’s end stack and Day G/L can differ.
Added / took off before hand
Shown when a player’s start stack differs from where they ended their previous hand.
Cards
Hole cards as recorded; blank when they weren’t captured.
Delay
This page runs on the same delay as the feed: a hand’s results appear only after that hand has finished on the delayed feed, so nothing is spoiled. Hand times shown are the live times the hand was recorded.
Updates
New hands are added about every 5 minutes during the session. This page checks for them every minute.
